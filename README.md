## Spring Boot REST API

This project is a simple **Spring Boot REST API**.

### How to Run

1. Open the project in **Android Studio**.
2. Run the application as an Android application.
3. Configure the base URL depending on your device.

### Base URL Configuration

- **Physical device**  
  If you are running the app on a real device, update the base URL to your laptop’s local IP address:

  ```text
  http://192.168.100.20:8092/springboot-rest-api/api/v1/transactions/send-money

- **Emulator device**  
  If you are running the app on an emulator, update the base URL to:

  ```text
  http://10.0.2.2:8092/springboot-rest-api/api/v1/transactions/send-money
